# ParquetTools – Design

PowerShell binary module (C#, netstandard2.0, PS 5.1+ and 7+) for reading Apache Parquet files. Mirrors the structure of PSAvroTools. Repo: `PSParquetTools`; module: `ParquetTools`.

## Scope (v1)
Read-only. Writing (`Write-Parquet`) is a separate later spec/cycle.

## Constraints
- Intended for public GitHub and PowerShell Gallery under a personal account. No employer-related data anywhere: code, docs, samples, test data, CI config, manifest author, commit identity.
- Dependency: Parquet.Net (pure managed). Companion DLLs (compression codecs etc.) are bundled by `publish.ps1`.

## Cmdlets
### `Read-Parquet`
- `-Path <string[]>` (Mandatory, Position 0, ValueFromPipeline, wildcards supported).
- `-Column <string[]>` (optional): read only these columns.
- Behavior: for each file, open `ParquetReader`, iterate row groups, read requested columns, emit one `PSObject` per row. Streams per row group (low memory).

### `Read-ParquetSchema`
- `-Path <string>`: returns schema (column name, type, nullability, nesting).

## Components
- `ReadParquetCmdlet`, `ReadParquetSchemaCmdlet`: parameter handling and output only.
- `ParquetRowMapper`: converts Parquet.Net column data for a row group into PSObjects; independently testable.

## Type mapping
Primitives → matching .NET types; timestamps → `DateTime`/`DateTimeOffset`; decimal → `decimal`; binary → `byte[]`; null → `$null`; struct → nested `PSObject`; list → array; map → ordered hashtable.

## Errors
Missing file or unknown `-Column` → non-terminating error naming the file/column. Corrupt file → per-file error; remaining files continue.

## Testing
Pester 5 in `IntegrationTests/`, using small generated sample files with generic data (flat, nested, nulls, column selection, multiple row groups). Samples are generated by a script using Parquet.Net; no real data is shipped.

## Packaging
`ParquetTools.psd1` (neutral/personal author), `publish.ps1`, GitHub Actions build/publish workflow, README with usage examples, MIT licence under the personal name.
